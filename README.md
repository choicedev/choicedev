### 👨‍💻 Sobre Mim

Desenvolvedor Android com mais de 3 anos de experiência no desenvolvimento de aplicações nativas, focado em **Kotlin**, **Jetpack Compose** e arquiteturas escaláveis (**MVVM**, **Clean Architecture** e **MVP**).

- 🏢 Atuando no desenvolvimento e manutenção de apps com **Kotlin/Java**, integração com APIs REST e persistência local.
- 📱 Experiência com **Jetpack Compose** e **XML** para construção de interfaces modernas e reativas.
- 🛠️ Domínio em injeção de dependências (**Hilt**), banco de dados local (**Room**, **SQLite**) e rede (**Retrofit**).
- 🔄 Prática sólida com controle de versionamento via **Git** / **Git Flow** e metodologias ágeis (**Scrum**, **JIRA**).
- 💡 Comprometido com boas práticas de engenharia de software, código limpo e aprendizado contínuo.
